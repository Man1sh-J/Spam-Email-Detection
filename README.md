# Spam Email Detection using Machine Learning

A machine learning web application that detects whether a message is **Spam** or **Not Spam** using Natural Language Processing (NLP).

## Project Overview

This project uses machine learning to classify text messages. Users can enter a message through a web interface and receive a spam detection result.

## Technologies Used

- Python
- Flask
- Scikit-learn
- TF-IDF Vectorization
- HTML and CSS
- Machine Learning and NLP

## Features

- Detects spam and non-spam messages
- Simple and user-friendly web interface
- Uses a trained machine learning model
- Provides instant predictions

## How to Run Locally

1. Clone the repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Start the application:

   `python3 app.py`

4. Open `http://127.0.0.1:5000` in your browser.

## Project Structure

- `app.py` — Flask application
- `spam_model.pkl` — Trained machine learning model
- `tfidf_vectorizer.pkl` — Text vectorizer
- `templates/index.html` — Website interface
- `requirements.txt` — Python dependencies

## Disclaimer

Predictions are generated by a machine learning model and may not always be accurate.
